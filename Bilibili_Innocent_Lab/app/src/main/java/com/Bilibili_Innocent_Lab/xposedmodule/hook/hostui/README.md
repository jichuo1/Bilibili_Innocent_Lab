# 宿主 UI 接入

宿主视觉使用凝光 1.5.1 的公开 API，`lumen-engine` 与 `lumen-motion` 使用同一正式版本的发布产物。`hook/feature` 只负责能力发现、Hook 安装和运行时诊断，具体 UI 装配放在本目录。模块自己的设置界面仍在 `ui/activity`；宿主视觉代码不再依赖那里的材质或导航实现。

旧原生首页与 khome Compose 首页独立接入。`chrome` 目录在已验证的业务 Composable 作用域内装饰最终 LayoutNode Modifier，绕过 R8 在方法体内覆盖默认入参的情况；只处理局部顶底栏，保留宿主测量、点击、指针与无障碍。作用域异常时释放，延迟 ApplyChanges 按装饰 Modifier 的身份关联节点；材质失败只恢复仍由本模块持有的原 Modifier。找不到独立取样内容层时使用窗口基色与祖先背景的安全回退，不递归取样整屏 ComposeView。

原生 root 在实际装配成功后才去重，布局未就绪有限重试。原生路径装配完成、新版路径真正绘制后才记 APPLIED；注册、观察与应用分开报告。组件过滤、扫描选择保留和相关验证边界见 [宿主组件兼容](../../../../../../../../../../docs/host-component-compatibility.md)。

| 模块 | 宿主职责 | 引擎接口 |
| --- | --- | --- |
| `common` | 读取宿主换肤、寻找独立内容层、管理注入区域生命周期、适配帧时钟 | `LumenPalette`、`LumenSurfaceSession`、`LumenSurfaceBinding`、`LumenSurfaceLegibilityController`、`LumenSpring`、`TouchGlowRenderer` |
| `top` | 原生分类布局、收岛输入与刷新/回顶、列表占位、融合带位置 | 局部采样表面、自定义形状输入、渐隐预设、弹簧与柔光 |
| `bottom` | 原生标签槽位、隐藏项、发布入口、拖动落点与点击转交 | 浮动与选中表面、弹簧与柔光 |
| `cards` | 列表识别、播放器排除、封面轮廓、信息区间距与坐标裁剪 | `LumenFluentControl` 共享亚克力场、CARD 层级与静态表面 |
| `follow` | 关注页标题、卡片排布、选中项、复用与状态栏位置 | 局部表面会话、`LumenSlidingSelection`、线性渐隐扩展 |
| `overlays` | 复制气泡的定位、独立文字层与选择时机、回复脉络的背景透明度和关闭释放 | `BubbleDrawable`、`LumenEasing`、静态表面会话 |

## 首页旧新框架接线

8.92.1 起同一 APK 可以同时含原生首页与 khome Compose 首页，入口是否存在不能代表当前路由实际命中。原生顶栏除旧 `onViewCreated` 点外，使用已验证首页 Fragment 的 `performViewCreated` / `performResume` 分发兜底；底栏只查找已验证 TabHost 类型。布局未附着、尺寸为零或子项未生成时有限重试，实际装配后才记入去重集合。注册状态使用 `installed`，进入业务回调使用 `OBSERVED`；原生 controller 完成装配或 Compose 真实绘制后才上报 `APPLIED`，异步异常单独上报。

`chrome/HomeChromeComposeLocator` 按稳定源码 facade、语义 trace 和完整 ABI 验证顶栏、底栏与标签项。顶栏同时保留有/无 boolean 及末尾 Compose mask 的两种 ABI；底栏与标签项允许一或两个 mask。后台 DexKit 查询复用共享适配会话，缓存只在再次通过 ABI 验证后使用；不能依赖 R8 方法字母或只保留在旧样本中的 lambda EnclosingMethod 注解。

Compose 入口的 Modifier 入参可能被 R8 覆写，因此以业务方法作用域和 `ComposeUiNode` 的标准 Modifier setter 身份限定最终布局节点。顶栏作用域只装配首个根节点。底栏外根只负责胶囊裁剪与用户启用的布局；独立内容作用域在主 Row 才装配材质与柔光，使其位于原生底图之上、图标与角标之下。原生底图与图片请求保留。主 Row 通过已验证 rowMeasurePolicy 方法名锚点之后的直接内容调用者确认，最多检查 48 帧，不依赖 Hook 框架的随机包名；图片内部的 Row 不会取得此资格。嵌套有独立栈，原方法抛异常也释放作用域。无作用域的 Updater Hook 立即返回。原生背景元素只在当前根的不可变副本中替换；以已验证的四/五项字段及构造结构预筛，再调用宿主背景工厂生成不绘制的 probe 认证真实类，避开 R8 私有类改名。保留其它布局、裁剪、点击、滑动与装扮前景元素；整个 AndroidComposeView 不缩放、不重排。

Compose 绘制使用凝光公开会话与材质入口。一个透明、不可交互的局部 overlay View 仅提供真实坐标和生命周期，自动绘制为空；材质由同一根的 draw modifier 绘制一次。实际内容来源优先选择与栏附近相交的独立原生列表，找不到时仅取窗口与祖先背景，绝不采样包含注入栏的整个 ComposeView。detach 释放所有绑定、视口代理和会话，再 attach 后按需重建。材质异常会停止该绑定，并在主队列分别恢复外根与前景 Row 上仍由本会话持有的确切原 Modifier；宿主后来的替换优先保留。

“小底栏”和“仅图标”只在用户启用时给底栏根添加原生高度与水平留白，使 BoxWithConstraints、原图标和点击区域一起重新测量。仅图标以独立标签项作用域移除标题 Text 整个叶子，不留布局占位，标题补入父项 contentDescription；发布入口和后续角标仍归宿主。触控柔光直接观察 AndroidComposeView 自身的 dispatchTouchEvent，仅在已登记的局部栏命中，绝不消费或改写事件。顶栏跟随宿主已有的折叠和位置变化，不另建全屏手势层。

跨版本结构证据与软件回归不能替代真实宿主像素或触摸验收；诊断也不能把结构覆盖率解释为运行命中率。

## 表面与生命周期

顶栏、底栏的视觉参数集中在 `common/HostSurfaceStyle.kt`，关注页参数在 `follow/FollowFeedStyle.kt`。新增外观优先调整公开 options/preset，不引入本地 Shader、位图模糊、NinePatch 阴影或自绘材质 Drawable，也不引用引擎 `internal` 类型。

`HostSurfaceScope` 为每个注入区域持有局部会话。每个 Drawable 只由它所绑定的 View 持有；收岛外壳使用独立的真实 View，不把 dock 的背景搬到输入层 Canvas。采样源必须是独立内容层，排除自身、祖先和注入装饰。宿主布局、padding、文字与点击行为由适配层保留。

区域 detach 时关闭会话与图形资源，重新 attach 时重建绑定；宿主覆盖背景时重新绑定，关闭时仅恢复本会话仍持有的背景。配色来自宿主 `NightTheme` 和 `ThemeUtils`，反射入口只在装配时解析。位置变化通过 `notifyPositionChanged` 通知引擎，形状输入按几何变化更新，避免逐帧重建 Drawable。

第三方 Activity 不调用 `LumenActivityDelegate.prepare` 或 `bindRoot`，局部表面不读取引擎偏好、不接管宿主窗口。复制气泡拥有自己的 Dialog，使用公开 `BubbleDrawable` 绘制外壳；适配层保留原来的按文字限宽布局、顶部箭头、底部 20% 安全区与独立文字淡入，200ms 入场、150ms 离场、120/100ms 描边淡入淡出。1.2.0 的默认 presenter 会改变宽度和文字运动，所以不用于此处。关闭开始时交还触摸，销毁 owner 时关闭 Dialog 并注销会话回调。回复脉络面板的会话随其原有 controller 释放，透明度仅影响填充色，描边保留原不透明度。

顶栏弹簧参数与原实现一致：收起刚度 115、阻尼比 0.84；展开 88 / 0.68；按压反馈 420 / 0.8。`HostSpringAxis` 只适配帧时钟和重定向，把原参数传给引擎；静止判据保留位置容差与 20 倍速度容差。60/90/120Hz 回归直接比较迁移后的轨迹与原算法，覆盖收尾、过冲和带速度反转。回复面板使用原 standard 曲线，保持 180/150ms 进退场与 160ms 回复树淡入。

深色栏通过引擎公共可读性扩展保留原 8Hz 亮度/细节统计、宿主灰色前景对比度补偿、0.92 色罩上限、迟滞和 240ms 过渡。采样区域来自绑定的实际形状，随会话、内容层与主题变化释放或重建；亮色和静态选中项不启用探针。白色渐变描边、原色罩强度、采样层独立 alpha 和采样失败时的半透明回退均通过公开参数声明。

`HostOverlaySurfaces` 还处理静态面板从零 alpha 恢复可见的绘制刷新：1.2.0 在零 alpha 时跳过背景，而 Android 属性动画可能复用该空白硬件绘制缓存。适配层只在恢复可见的那一帧 invalidate，不增加逐帧采样，并在关闭时移除观察器。更新引擎时保留真实窗口 PixelCopy 回归，确认上游修复后再去掉适配。

“卡片材质”是原版、亚克力、云母（Mica）三选一配置，默认原版，依赖“视频卡片悬浮美化”，重启宿主后生效。原版不建立共享材质管线。原生视频列表、追番/影视 Compose 海报、动态外层分组与引用卡片共用 `HostCardMaterialScope`：亚克力每视口只建立一个 `LumenFluentControl` 和采样绑定；云母由 `HostCardMicaField` 在后台准备静态宿主背景，复用一个 `LumenMicaBackdrop` 及 CARD 层，滚动不重新采样或模糊。卡片按真实窗口坐标裁剪同一材质结果，各自保留描边、阴影与圆角。API 29 起使用共享 RenderNode，旧系统或软件 Canvas 使用 Picture；材质、噪点与模糊均由引擎绘制，不在模块重写。单视口亚克力 GPU 上限 8,388,608 像素用于容纳页面及 48dp 模糊边距，其余预算沿用引擎默认值。

采样源只绘制窗口基色和视口及祖先的真实背景，不包含封面、文字或卡片自身；源代理透明，材质目标裁掉自身输出，两者不改变布局、触摸或无障碍。壁纸版本、尺寸、主题或引擎状态失效时重录材质，位置改变仅更新裁剪矩阵。硬件 RenderNode 与软件 Picture 分别缓存，顶栏的软件取样不能替换屏幕显示列表引用的 GPU 节点，视口尺寸改变也保留节点身份。Compose 用宿主的布局坐标回调及 Snapshot 状态使绘制缓存随位置失效；各卡片使用独立 Drawable，避免共享 bounds 或 callback。原生信息区的无 id `TintView` 底板只在亚克力开启时临时透明化，离屏恢复仍由本层持有的原背景。动态暂停时释放共享场，视口 detach 时关闭会话与录制资源。低内存、省电、失焦或预算不足的回退由引擎策略处理。播放器及播放结束页继续排除；评论关系线、刷新箭头等业务图形仍由原内容 View 绘制。

三种材质均按窗口中的真实可见区域跳过缓存分页的逐帧工作，不能只看 `isShown`；重新进入可见区域后恢复。亚克力的 GPU 模糊输入及共享柔化合成层使用半尺寸，面积降为四分之一，卡片边框、圆角、封面和文字仍按原分辨率绘制；软件 Picture 及 Mica 共享层保持原尺寸。像素回归同时对照完整分辨率的参考材质。

关注页状态栏融合带以及顶底栏玻璃通过局部坐标代理限定实际录制尺寸，保留四倍模糊半径的邻域，避免只裁剪 Canvas 却仍分配整屏纹理。版本读取观察原内容的失效与裁剪窗口几何，避免透明代理长时间 dirty 导致静止页面反复录制；内容原地更新及仅属性位移仍须更新当帧取样。顶底栏的明暗探针只读取原生前景，玻璃输入则保留祖先背景；代理继承内容可见性，并单独保留祖先自采样保护，关闭时先解绑再移除代理。

顶底栏的 `ViewOverlay` 代理没有通往内容 owner 的普通父级链，裁剪范围必须先映射到代理实际父容器的坐标系，再与同坐标系的内容边界求交。把 owner 局部范围直接作为代理 layout，会在 owner 存在顶部占位、平移或缩放时错置采样窗口；GPU 即使报告成功，透明的缺失区域仍会漏出清晰原图。版本计算检查采样邻域内可见子树的失效、尺寸、滚动、透明度和相对矩阵，跳过透明代理及被裁在邻域外的分支；仅检查 owner.isDirty 会漏掉硬件 ViewGroup 的子节点失效，使软件位图冻结。`HostChromeViewportInstrumentedTest` 用宿主相同的 244px 顶部偏移和细条纹检查 GPU/软件输出及内容更新，并对照完整采样验证位置变化、源平移、滚动、静止录制次数与重绑定。

真机底栏容器还会遗留 `View.alpha = 0.98`：即使采样 alpha 为 255、`backdropOpacity = 1` 且后端正常，整层合成仍混入 2% 的清晰原图。玻璃接管时通过 `prepareGlassContainer` 将容器 alpha 归一化为 1，透明感由材质自身提供；不在逐帧回调中强制 alpha，后续原生显示/隐藏动画保持控制权。细条纹回归包含 0.98 的负对照和接管后的真实像素，并检查之后的 0.5 淡出值不会被覆盖。

`background` 生成页面后方的装饰画面，不承担玻璃材质。内置预设通过列表滚动 Hook 驱动连续世界，卡片与背景速度为 2:1：先累计原始内容距离，再以一半距离绘制背景，保留细小位移与反向滚动。稳定回顶恢复原点，各标签保留自己的距离，共享详情页壁纸在横向切换时平滑过渡。自定义图片保留原有固定视口行为。首页与动态子页透出所属窗口的同一张壁纸，避免标签栏和正文重启图片。底层云气、银河、星点及流星仍按固定种子的世界区带生成，同一配方与视口尺寸可稳定重建；相邻区带保留跨界光晕和过滤余量。共享位图 LRU 上限 24 MiB，活跃页面仅持有当前视口所需区块。星空、星云、流星固定为夜空配色，其他柔色预设保留主题适配；自定义图片沿用缩放与遮罩缓存。

## 顶栏与底栏材质配置

`HostChromeAppearance` 管理用户选择，`HostSurfaceStyle` 声明引擎参数，`HostSurfaceScope` 统一应用材质与后端；融合带也遵循所属顶栏的渲染选择。顶栏、底栏分别支持柔光透镜（默认，映射 FROSTED）、透明玻璃（映射 LIQUID）与液态玻璃（映射 Prism，使用独立的 `LumenPrismGlass` 入口）。高级渲染提供自动（GPU 优先）和软件兼容。Liquid 的完整效果需要 API 33 与可用 GPU；软件兼容在 Liquid 下不可选，并保留切换前柔光的后端选择。导入 Liquid 到旧系统会回退为柔光。

液态玻璃在两栏的“玻璃材质”菜单中独立选择，存储值 `prism`，设置目录版本为 v56，默认与旧用户选择保持不变。它自动选择渲染后端并保留切换前的柔光后端；API 33+ 提供完整折射，31–32 只有模糊与饱和度，27–30 使用引擎软件回退，不把旧系统的液态玻璃意图改写为其他材质。底栏继续保留宿主原生标签、选中框及点击协议；引擎 `LumenNavigationBar.setPrismSelection()` 属于独立组件，不能直接调用到宿主的原生底栏上。

`HostPrismSurface` 只处理真实 View 的宿主接线：把引擎表面放在宿主目标之前的同级 View 中，同步尺寸、缩岛 inset、矩阵对应的属性、透明度与可见性；折射、模糊、高光和外阴影由正式引擎绘制。多个同级表面共享父级裁剪所有权，最后关闭时才恢复；背景只在仍属于本模块时恢复。Prism 自带外阴影，因此底栏不创建额外 `HostBottomBarShadow`，宿主自身的 Outline 仍用于裁剪子内容。

棱镜公开入口接受 View 来源。`HostChromeViewportSource` 为它提供位于捕获子树外的透明坐标代理，绘制包含窗口基色、实际祖先背景和内容的裁剪场景；保留自采样禁止检查、内容版本、局部视口和 detach 释放。每个栏复用自己的会话，不逐帧创建材质、更新选项或编译 Shader；静态选中表面和融合带继续按原有公共接口绑定。

旧配置和旧备份的隐藏 `legacy` 后端保留顶栏 AUTO、已启用底栏 SOFTWARE；首次新开启的栏选择 AUTO。界面第一次保存时写入明确选择，无需启动时批量改写用户偏好。合入主分支后新增四项设置属于目录 v45；已发布的 v44 保留 SponsorBlock 两项，可备份、导入、收藏定位，并随重启宿主生效。

普通胶囊 GPU 模糊恢复为原 RenderEffect 17dp，软件三重盒式模糊为 10dp；这是两种算法的等效强度映射，不是统一设成相同数字。柔光与旧 Liquid 使用同一组模糊声明；Prism 使用上游默认的 8dp 模糊、1.5 饱和度和 24dp 边缘折射，当前不开放滑杆。

柔光采样使用 `backdropOpacity = 1`，色罩保持原 112/120：模块 `FrostedMotionSurfaceAlpha.sampleAlpha` 在完整帧上归一化为 255，不能再把采样乘上 `(1 - tintOpacity)`。旧宿主单层合成遗留的这一乘法，会让浅色约 31% 的清晰底图从模糊层下面漏出，增大模糊半径也无法消除。Liquid 保留独立的清透采样比例；深色可读性控制只调整色罩，不覆盖调用方声明的采样透明度。

`HostChromeOpacityInstrumentedTest` 直接实例化模块完整柔光 renderer，以相同细条纹和文字对照宿主，覆盖浅色、深色可读性补偿和 Liquid 区分。额外底色色罩不能替代采样透明度归一化。该测试不写用户偏好，输出保存在忽略目录 `captures/lumen-1.2.0/opacity-20261008/`。`HostChromeRenderingInstrumentedTest` 的独立算法参照也使用模块实际的 255 采样 alpha。
