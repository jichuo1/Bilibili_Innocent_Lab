# 设置界面的用途与区域分类

2026-09-05 起，原有混合的进阶设置拆为「净化进阶设置」和「增强进阶设置」。两者分别放在
「净化」与「增强」主栏的末尾。本文记录界面归属；偏好键、默认值、备份 ID、Remote 配置
及宿主 Hook 的行为保持不变。

同日进一步将「实验性功能」整理为固定主栏，下设独立展开的「外观」和「兼容」。原显示设置
卡片中的语言与桌面图标选项一并移入外观。

## 分类规则

- 净化：移除广告、运营引导、指定内容、界面组件或提示。辅助过滤判断的选项随过滤功能归类。
- 增强：增加阅读能力、改变浏览或评论交互、调整播放和显示方式。
- 依赖项放在一起：「保留大会员卡片位置」仍和隐藏卡片放在「我的页」；「匹配增强／强力模式」
  仍在相关推荐过滤面板。不能仅凭名称中的“增强”把过滤参数移入增强栏。
- 跨区域共享规则保留一份入口并标明范围。视频时长规则同时作用首页推荐和详情推荐，单列
  「首页与详情页共享过滤」，避免重复入口或误认成只作用某一页面。

## 净化主栏与进阶菜单

主栏保留视频详细页广告、视频暂停页广告和首页大卡轮播等既有快捷开关。主栏末尾是默认收起的
「净化进阶设置」；其中六个页面区域独立折叠，共享过滤保留直接可见的小标题和配置入口。

| 区域 | 功能与配套配置 |
| --- | --- |
| 首页推荐与布局 | 隐藏首页游戏中心、搜索推荐词；自定义首页标签及组件；过滤伪装信息流广告、普通推荐广告、图文、游戏推广、直播、课堂、大卡；推荐标题关键词开关和关键词规则 |
| 底栏与动态页 | 自定义底栏隐藏规则与扫描选择器；隐藏动态页同城、校园标签 |
| 我的页 | 隐藏大会员卡片、保留其位置；自定义组件隐藏规则与扫描选择器 |
| 播放页与竖屏流 | 隐藏竖屏切换按钮、播放器互动组件、影视自动活动半屏；竖屏内容过滤面板；相关推荐过滤面板 |
| 评论区 | 隐藏整个评论区；关闭关键词搜索链接；隐藏空评论引导、投票、关注按钮、体验反馈、运营推广；评论关键词过滤及规则；按用户等级过滤及最低等级 |
| 启动与提示 | 开屏广告净化、青少年模式提醒、客户端更新提醒 |
| 首页与详情页共享过滤 | 推荐视频最短／最长时长，同一规则同时作用首页与视频详情推荐 |

两个内容过滤面板保留完整的内部能力：

- 竖屏内容过滤：主页竖屏推荐，以及竖屏流中的广告、直播、游戏、番剧影视、课程、短剧、带货、
  电影、纪录片、电视剧、综艺、音乐。面板中已有的范围说明和类别联动保持原逻辑。
- 相关推荐过滤：商业推广、游戏、直播、课程、特殊推荐，以及匹配增强、强力模式、推荐理由过滤
  和关键词。其最终作用是过滤内容，因此整个面板归于净化。

## 增强主栏与进阶菜单

「自由复制」改为增强主栏中的小标题，评论复制和简介复制两个开关保持原行为。其后的
「复制气泡外观」集中自动跟随亮暗色、手动亮色两个选项；自动跟随从实验性功能移到这里，
原有覆盖关系、二次确认和提示更新逻辑保留。

增强主栏末尾是默认收起的「增强进阶设置」。首页与动态页、视频播放页、评论阅读与交互、
数字显示四个区域与净化使用同一套独立折叠卡片，默认收起，可以同时展开。

| 区域 | 功能 |
| --- | --- |
| 首页与动态页 | 竖屏视频进入详情页；动态页默认显示视频标签 |
| 视频播放页 | 默认播放画质；播放器状态栏透明 |
| 评论阅读与交互 | 回复脉络图；关闭评论正文／卡片点击快速回复 |
| 数字显示（全局） | 显示完整播放量、点赞量等数字 |

「关闭点击快速回复」改变正常评论交互方式，归于增强；「关闭评论关键词搜索链接」去掉搜索
导流入口，归于净化。它们继续复用各自已有安装器，不因界面归属而拆分或改写 Hook。

## 实验性功能：外观与兼容

实验性功能不再整体折叠后再找内部选项。两个二级菜单并列、默认收起，可以同时展开。

| 二级菜单 | 小分组与内容 |
| --- | --- |
| 外观 → 风格与配色 | 界面美学、Liquid Glass 背景、SPEC 2021／2025 开关 |
| 外观 → 显示设置 | 应用语言、隐藏桌面图标及原有提示 |
| 兼容 | 免 Root 支持、漫游版本支持扩展、预见式返回动画、重新适配当前版本 |

预见式返回继续在 Android 16 及以上整组隐藏，已有偏好及平台判断不变。更换皮肤／SPEC 的
保存与界面重建、背景图片处理、语言切换、桌面图标显隐、兼容配置发布及适配确认沿用原逻辑。

外观内容容器统一提供水平边距，入口行不再额外叠加横向 padding；入口标题与开关标题使用同一
文字起点和行右边界。两个进阶菜单分别沿用净化星形与增强魔棒图标，便于与所属主栏对应。
增强魔棒、外观调色盘、兼容拼图来自 Google Material Design Icons，使用本地 24×24 矢量资源
和已有主题着色；来源与 Apache-2.0 许可证记录于 `THIRD_PARTY_NOTICES.md`。

## 布局、搜索与兼容边界

两个进阶入口在构建 View 树时直接成为各自主栏的最后一个子项，旧的“移动到实验性功能之后”
逻辑已移除。首帧前只整理区域内既有 View，不复制功能控件、不重绑监听器。

区域分界只按标题位置切分。下一个标题前的最后一个控件／说明属于当前区域，不能继续使用
旧布局“减一跳过分隔线”的假设。输入不完整时保留原始布局；单测验证不同区域数量时，所有
非标题子项恰好被分入一个区域。

搜索结果显示「用途进阶设置 · 作用区域」路径，能索引收起的区域。选择结果时展开正确的进阶
菜单及所需区域，再滚动并高亮；另一个用途菜单的展开状态不变。全部展开／收起继续只动画
alpha、translationY 和箭头 rotation，不逐帧修改高度或创建超长硬件层。
外观与兼容也走同一菜单状态与动画入口；搜索能索引收起的内容，并在命中菜单标题时直接展开
该菜单。Activity 销毁时清空四个菜单的 View 引用并取消动画。

静态重排审计确认：配置常量引用的集合及出现次数一致；62 段实际开关回调正文除缩进外完全
一致。SettingsCatalog 仍为 10（86 项），VersionAdapter 仍为 schema 53 / rule 47。
本次不涉及配置协议迁移、宿主适配规则或框架入口变更。

## 功能开关菜单的统一水平留白（2026-09-05 补记）

净化进阶分组内的开关是基准：菜单壳 8dp，加上分组内容 12dp，控件距离二级菜单边框合计
20dp。增强进阶以前只有菜单壳的 8dp，兼容以前只有 10dp，因此视觉上明显贴边。

当前由 `SettingsMenuSpacing` 统一维护：增强和净化使用同一分组内容容器提供 12dp，增强
进阶根不再重复加 padding；兼容保留原 10dp 菜单壳，
在内容根补足剩余距离。兼容使用已经换算的菜单壳像素值计算差额，避免不同屏幕密度下各层
取整后出现 1px 偏差。原净化开关的位置保持不变。默认画质和重新适配入口取消额外水平缩进，
跟随所在内容容器；分组小标题也随增强内容根一起内收。

新增同类功能菜单必须复用这份规则。不要给每个开关单独补 padding，也不要全局修改
MaterialSwitch；不要把“相同内层 padding”误认为“相同最终留白”。带前导图标的操作行以整行
边框对齐，文本自然位于图标后方。外观已有的标题对齐保持原规则。

兼容菜单标题按用户要求简化为「免 Root 支持」，NPatch 的说明保留在正文。不要为了长标题
削小统一留白；真机回归同时检查该标题没有省略号。

真机回归直接比较净化、增强、兼容三处控件相对菜单外框的左右距离，覆盖增强所有七个入口、
兼容的免 Root／漫游，以及支持时的预见式返回。这样平铺或折叠层级变化后也能检测边距漂移。


### 增强区域折叠的后续调整

按用户要求，增强的四个区域已从平铺小标题改为与净化一致的折叠卡片。每组有标题、强调色标记、
箭头和独立展开状态。展开一组不关闭其他组；收起并重新打开增强进阶时，子组状态仍然保留。
搜索命中某个增强功能时会同时展开增强进阶和所属区域。

12dp 内容留白下沉到共享分组构建器，不能保留此前平铺根的 12dp 再叠加，否则会得到 32dp
错误总留白。跨菜单几何回归会先展开各组再比较，继续锁定与净化相同的 20dp 基准。
