# 宿主首页与组件过滤的兼容边界

宿主同一安装包可同时包含原生旧首页和 khome Compose 首页，也可能同时保留 Mine、MineV2、MineV3。类存在、方法可 Hook、签名与旧版一致，都不能单独证明页面实际使用该入口。宿主版本之外，还需要检查账号实验配置、屏幕档位和实际消费路径。

## 首页装配

- 旧原生首页与新版 Compose 首页分别定位局部顶栏、底栏。保留宿主测量、点击、滑动和无障碍；不要缩放全屏 ComposeView 来模拟局部胶囊。
- 语义锚点与完整运行 ABI 一起验证，避免依赖 R8 每版变化的字母类名。带 Modifier 参数也不等于该参数有效：R8 可能保留声明，却在方法体内用默认值覆盖入参。
- Compose 路径应在确认的栏位作用域内处理最终节点的 Modifier，不对全页面控件批量改写。所有临时作用域必须在宿主异常时退出。
- 底栏的外层尺寸节点与实际内容行分开处理。原生底板／装扮图在外根之后绘制，外根的 `drawBehind` 会被遮盖；材质承托应定位到背景之后、图标之前的原生内容行，并在异常回退时恢复自己修改过的每个节点。
- 库内元素和语义键也会被 R8 改名。背景元素先校验字段／构造形状，再用宿主背景工厂返回的真实类型确认；无障碍描述使用宿主的标准属性键实例，不能新建同名键替代。只在完整语义能力可用、当前节点已挂接描述后，才移除仅图标模式的文字。
- 原生布局未就绪允许有限重试。只有成功找到并装配的 root 才可去重；失败不能永久占用 root 标记。
- 材质通过凝光正式公开 API 装配；局部采样、独立内容层、detach 释放及自采样排除沿用 `hook/hostui/README.md`。异步回调需要独立异常保护，Hook 框架的保护范围不包含之后执行的 View.post。

## 我的页过滤

- 配置由 selector、旧 ID 和标题规则取并集；扫描空配置时仍应可用。保留宿主“设置”入口，过滤后的数据不能让宿主补设置时对空列表取最后一项。
- 普通 item、整个 group、group 附属 button、live_tip 是不同能力。只注册 item getter 不能对其他类型宣称完整支持。
- 在新旧实际数据边界处理 AccountMine、AccountMineV2；getter 是独立备用路径，不能因为一个闲置 getter 注册成功而抑制其他已知安全入口。
- 新模型字段可能已被 R8 重命名。优先以宿主序列化协议的元素身份确认槽位，再严格验证真实对象与字段对应关系；空值、歧义或未知模型必须安全放行并报告未确认，不能按字段字母顺序猜写。
- 序列化探测只捕获根级元素，不构造 JSON、不递归编码业务数据，不保留宿主账号模型。缓存成员元数据并限制重试，避免把字段扫描放进每项绘制。
- 精确零参方法／构造器查询必须明确设置空参数约束。KavaRef 的 `parameters(*emptyArray())` 只添加空条件，不能表达零参；统一查找层使用 `emptyParameters()`，避免误选同名重载。规则代际变化会重新验证已缓存的旧落点。
- 过滤应作用于数据与其布局占位；仅把文字或 View 设为不可见会留下空白，不能作为整组屏蔽成功的判据。

## 扫描与用户选择

扫描是观察，不是用户修改指令。一个非空快照仍可能只包含刚加载的分组，后台推送、实时查询、模块更新、宿主升级或降级，都不能据此删除尚未观察到的选择。

快照存储只写组件缓存与来源，不读写 selectors 或手填规则。用户在面板确认时，才合并当前可编辑项；未知项继续保留，明确取消应清除该项主键与精确别名，之后扫描也不能重新勾选。跨面来源与选择保持隔离。

## 实际生效证据

诊断阶段必须区分：

| 阶段 | 最低证据 |
| --- | --- |
| 注册 / 安装 | 成员解析与 Hook 注册成功 |
| ADAPTED | 安全入口、运行 ABI 与必需能力确认 |
| OBSERVED | 宿主真的执行到目标页面或数据路径 |
| APPLIED | 实际装配／绘制成功，或过滤确实改变了宿主数据 |
| ERROR | 目标路径执行或异步装配失败，已安全放行 |

不得在异步装配排队时提前标 APPLIED。日志可记录固定路径码、计数和支持的组件类型，不记录规则原文、标题、URI、账号模型或用户内容。没有匹配项不等于功能失效；没有宿主回执应显示未知，不将空计数解释成全模块失败。

后台适配仅补装新发现的边界，并复用已有安装实例；重复注册或后续无关布局的重试，不能把已经 APPLIED 的状态降为等待安装。

## 有效回归

单测需要真正执行 Hook 回调并消费返回结果，不能只验证注册 ID。至少覆盖：

1. 旧／新首页路线；R8 覆盖默认 Modifier；定位未就绪后重试；异常退出、嵌套作用域和目标外节点不变。
2. 真正装配前无 APPLIED；定位失败、宿主原调用失败、异步失败均无虚假成功。
3. Mine 新旧模型、混淆字段、普通项与附件分类型过滤、设置入口保护、无匹配放行、闲置 getter 与直接读字段的消费端。
4. 跨版本先扫描 A、后扫描 B，B 的原选择始终保留；空快照、别名确认／取消、同版本、跨面和扫描不读写选择。

云端矩阵按准确版本码、APK SHA、样本 revision 与工具提交固定输入，保留 partial/error 边界。旧版没有新框架属于正常缺席。静态调用图与结构验证不能冒充设备运行或视觉验收；软件验证结果应明确覆盖范围。
