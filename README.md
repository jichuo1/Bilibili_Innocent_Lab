## 项目简介

Bilibili Innocent Lab 是一个面向 Android 哔哩哔哩客户端的 Xposed/LSPosed 模块。项目的主要目标，是在尽量保持客户端原有视觉结构和操作习惯的前提下，对部分影响使用体验的界面内容进行净化，同时补全评论、视频简介、第三方扩展兼容和版本适配等方面的交互能力。

本模块并不是一个独立的哔哩哔哩客户端，也不会替代官方应用。它以运行时 Hook 的方式加载到目标应用进程中，对特定界面、数据绑定和交互入口进行有限修改。用户仍然使用原有的哔哩哔哩账号、播放器、推荐系统、评论区和视频详情页，只是在模块启用后，可以根据自己的需要开启或关闭相应功能。

项目强调“可选择、低侵入、可恢复”。绝大多数功能都提供独立开关，用户可以只启用自己需要的部分；模块不会要求所有功能必须同时开启。对于实验性功能，设置界面会给出明确提示，便于用户根据当前客户端版本和设备环境自行决定是否使用。

由于哔哩哔哩客户端会持续更新，内部类名、方法签名、布局结构和数据模型也可能发生变化，本项目加入了运行时版本适配、适配结果缓存和手动重新适配机制，尽可能降低客户端升级后功能整体失效的概率。但任何基于 Hook 的模块都无法保证永久兼容所有未来版本，使用前仍建议阅读版本说明和已知问题。

## 功能介绍

模块将功能拆分为独立开关，用户可以只启用自己需要的部分。原有净化与自由复制能力保持原先的开关行为；“进阶设置”中的新增能力默认关闭，启用后通常需要重启哔哩哔哩才能生效。若当前客户端版本没有找到足够可靠的适配入口，对应功能会跳过处理并保留宿主原有行为，不会为了强行生效而全局修改未知页面或数据。

#### 首页顶部栏

| 功能 | 说明 |

| 隐藏搜索推荐词 | 清除搜索框内自动展示的默认推荐词，不影响进入搜索页、输入关键词和正常搜索 |

### 📋 评论与简介自由复制

#### 评论区自由复制

启用后，长按评论正文会在当前内容附近弹出可选择文字的复制气泡。继续长按文字并拖动 Android 系统选择句柄，即可自由选取需要的片段，再通过系统浮动工具栏完成复制，不必复制整条评论。

- **支持范围**：普通评论、长评论、展开后的内容和部分回复列表。
- **完整原文**：优先读取评论数据中的完整原文，尽量避免只取得折叠状态下屏幕显示的省略文本，并保留原有换行。
- **Emoji 映射**：哔哩哔哩自有 Emoji 会尽量映射为可读的文字形式，减少复制结果中的空白或无意义占位符。
- **列表复用适配**：滚动期间延后批量绑定，列表稳定后分批处理当前视口附近的评论；页面引用采用弱引用管理，长按期间暂停可能争用界面帧预算的任务。
- **官方交互保护**：图片、按钮、媒体容器和三点菜单等官方交互区域不会被正文长按监听器接管；在带图评论中使用自由复制并关闭气泡后，评论图片仍可正常点击打开预览。

#### 视频简介自由复制

长按视频详情页简介后，可以使用同样的复制气泡选择部分文字。对于可展开简介，模块会尽量读取完整原文，并统一换行、清理末尾多余空白、处理图标或特殊 Span 产生的占位内容，同时保留正文段落结构。

#### 复制气泡外观

| 显示方式 | 说明 |
| --- | --- |
| 默认暗色 | 默认配色，无需配置 |
| 手动亮色 | 手动切换为亮色样式 |
| 自动跟随 | 跟随哔哩哔哩亮暗主题；开启后覆盖手动亮色设置，主题结果提前判断并缓存，避免长按弹窗时临时执行反射 |

气泡使用透明对话框承载系统选择句柄和浮动工具栏，点击气泡外部即可播放退出动画并关闭。

### 🌍 漫游版本支持扩展

“漫游版本支持扩展”用于配合已经安装并启用的哔哩漫游模块工作。它不是哔哩漫游的替代品，也不提供账号、解析服务器、访问密钥或网络代理服务。

当较新的哔哩哔哩客户端改变内部分析目标时，旧版漫游可能在读取或生成 Hook 信息时出现异常。启用扩展后，本模块会尝试修补已知的分析候选问题，并协助漫游重建完整缓存，使其设置入口、页面定制和相关 Hook 能力能够在已适配版本中继续工作。当前兼容处理包括：

- 在缓存损坏、过期或客户端版本变化时重新分析；
- 减少无意义的重复全量分析和冷启动等待；
- 在“我的”页面补充漫游设置入口；
- 通过跨进程 Provider、受权限保护的广播和本地缓存同步开关状态；
- 处理部分 MIUI/HyperOS 环境中的应用可见性与后台启动限制；
- 功能关闭后恢复相应原生行为，避免兼容状态长期残留。

> 开启该功能后，通常需要按照设置页提示重启哔哩哔哩两次，使缓存重建与后续快速启动路径依次完成。实际兼容性同时受哔哩哔哩版本、哔哩漫游版本和 LSPosed 分支影响。

### 🧪 实验性功能与自动版本适配

#### 预见式返回动画

在支持预见式返回手势的系统中，可以为模块设置界面启用系统提供的返回过渡预览。该能力主要面向 AOSP Android 14 及以上环境；部分厂商系统可能自行修改、限制或关闭对应动画。

#### 自动版本适配

哔哩哔哩更新后，混淆类名、方法签名和页面结构可能变化。模块会结合类结构、字段类型、方法参数与绑定特征定位各功能所需的 Hook 点，并记录客户端版本、安装包指纹和适配规则版本。适配成功后会缓存结果，后续启动在环境未变化时优先使用快速路径，减少重复扫描。

各功能拥有相互独立的安装与诊断边界；自动适配只能覆盖结构仍然相近的客户端版本，若宿主发生大规模重构，部分能力仍可能需要等待模块更新。

**升级哔哩哔哩后功能失效时**：

1. 打开模块设置，进入“实验性功能”；
2. 选择“重新适配当前版本”，确认清除记录；
3. 重启哔哩哔哩，模块会在下次启动时重新定位当前版本的功能入口。

## 安装方法

**准备**

1. 从 [GitHub Releases](https://github.com/jichuo1/Bilibili_Innocent_Lab/releases) 下载 APK；
2. 在 Android 设备上安装或覆盖安装模块。

4. 启用 `Bilibili Innocent Lab`；

## 推荐使用顺序

首次安装建议按以下顺序验证：

1. 确认模块已激活；
2. 只开启一个界面净化功能；
3. 重启哔哩哔哩并检查详情页或首页；
4. 测试评论区自由复制；
5. 测试视频简介自由复制；
6. 根据主题选择手动亮色气泡或自动跟随；
7. 确认基础功能稳定后，再尝试实验性功能；
8. 仅在已安装哔哩漫游且确有兼容需求时开启漫游扩展。

> 逐项启用更便于判断问题来源，也能避免多个模块同时修改同一页面时难以定位冲突。

## 常见问题

| 问题 | 排查方法 |
| --- | --- |
| 模块显示未激活 | 确认 LSPosed 已启用本模块，作用域包含官方哔哩哔哩；修改作用域后重启目标应用，必要时重启设备 |
| 开关已打开但功能没有生效 | 先强制停止并重启哔哩哔哩；刚升级客户端可尝试“重新适配当前版本”；漫游扩展可能需要两次启动完成缓存重建 |
| 评论长按没有出现自由复制气泡 | 确认评论自由复制开关已开启，且当前页面属于已适配的官方评论区；若只有少量评论失效，请记录评论类型、是否带图、是否为回复列表及客户端版本 |
| 使用自由复制后图片无法打开 | 当前版本已专门保护带图评论的媒体容器；请确认使用最新构建并彻底重启哔哩哔哩进程，仍可复现时请说明操作顺序及气泡关闭后到点击图片的间隔 |
| 气泡内无法选择或复制文字 | 确认没有其他模块同时 Hook 系统剪贴板、文本选择工具栏或 PopupWindow；部分厂商系统深度定制了文本选择组件，遇崩溃请提供系统版本和 crash 日志 |
| 首页轮播仍然出现 | 首页结构可能受账号实验分组影响；请提供客户端版本、首页样式截图和完整日志，避免只描述“功能无效” |
| 漫游扩展开启后仍然异常 | 请一并提供：哔哩哔哩、哔哩漫游、本模块、LSPosed（含分支）、Android/ROM 各自版本，是否完成两次重启，以及 LSPosed 中目标主进程的相关日志 |
| 与其他模块冲突怎么办 | 多个模块同时修改评论区、视频详情页、剪贴板、主题属性或漫游缓存时可能产生执行顺序冲突；建议暂时关闭其他模块仅保留本模块复现，确认单模块正常后再逐个恢复 |

## 性能与兼容设计

本模块包含多个运行在目标应用进程中的 Hook，因此在设计时尽量避免把复杂逻辑放入高频回调：

**热路径与调度**

- 对滚动、触摸和文本绑定路径设置快速返回条件；
- 评论绑定使用空闲调度与分批处理。

**缓存与生命周期**

- 反射获得的方法和字段会尽量缓存；
- 页面、Dialog 和评论 View 使用弱引用保存；
- 异步任务只持有 Application Context；
- 新版本适配结果写入缓存，避免每次启动重复扫描。

**兼容与豁免**

- 跨进程开关读取具有多级降级路径；
- 对自己的 Dialog、系统选择句柄和宿主媒体容器设置身份或来源豁免；
- 在 ROM 差异明显的窗口、状态栏和主题属性上使用显式配置。

项目不会为了追求“拦截更多内容”而无条件接管所有系统 API。对于 PopupWindow、Dialog、剪贴板、广播和触摸事件等影响范围较大的入口，优先根据对象身份、调用来源和手势生命周期判断是否属于模块目标，避免干扰图片预览、系统文本选择和宿主其他正常功能。
